# HID protocol

The custom RGB command uses a 64-byte HID payload. Linux hidraw writes prepend a zero report ID, for a total of 65 bytes.

| Payload offset | Value |
| --- | --- |
| 0–5 | `00 3a 00 00 01 02` |
| 6 | Bank, 0–4 |
| 7 | Index, 0–14 |
| 8–10 | Red, green, blue, each 0–255 |
| 11–63 | Zero in reports generated by the sender |

The dispatcher forwards reports with other headers to the original HID handler. The sender prints the report by default.
